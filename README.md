# ChatSphere

ChatSphere is a full-stack real-time messaging application. It allows users to create channels, join conversations, and send messages instantly using WebSockets.

## 🚀 Features

- **Real-time Messaging:** Instant message delivery using Socket.io.
- **Channel Creation:** Users can create and browse custom chat channels.
- **Secure Authentication:** User login and registration system.
- **Responsive UI:** Built with React for a seamless experience on all devices.

## 🛠️ Tech Stack

- **Frontend:** React, CSS, Context API (or Redux)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (or PostgreSQL/MySQL - update this to what you use!)
- **Real-time Communication:** Socket.io
